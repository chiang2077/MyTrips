## 做法
- 「豪斯登堡散步指南」8 張卡、「不看秀的晚上」4 張卡各加一顆「看詳細攻略」按鈕。
  夜晚的卡共用園區主題（登塔、葡萄酒祭 → 塔城；光之幻想城 → 光之幻想城；運河邊散步 → 阿姆斯特丹城）。
- 點下去開 `<dialog>`，內容放在 `index.html` 的 8 個 `.sheet`，由新檔 `htb.js` 切換。
  手機全螢幕、桌機置中；ESC、點背景、關閉鈕都能關；關閉後焦點回到原按鈕。
- 每個主題照 Lonely Planet 的格式：一句話為什麼值得去 → 必看 → 我們的走法（對應 10/28–31）
  → 附近吃什麼 → 實用資訊（時間、費用、限制）→ 資料來源連結。
- 查不到今年資料、或只找到去年版本的，一律標「待確認」／「依推斷」，不寫成事實。
- 陶瓷美術館 1/13 起暫停開放 ⇒ 標明暫停，不推薦。
