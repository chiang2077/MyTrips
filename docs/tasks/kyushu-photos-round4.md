## 改了什麼
1. 10/28（入住森林小屋那天）的影片與每日卡照片：原本 Commons 的逆光運河風車（`htbdusk.jpg`）
   → 豪斯登堡森林小屋官方頁「about」區的綠蔭湖畔小屋照（改名 `fvgarden.jpg`，1500×1000）。
   跟旅宿卡用的 `forestvilla.jpg`（官方 KV 湖景）是不同張。
2. 11/01 天神：舞鶴公園銀杏 → 日本國家旅遊局（JNTO）天神景點頁的渡邊通主街照
   （三越、藍天、車流；原圖 3888×2592，縮到 1600×1067）。
3. 手機版影片動態：原本只有放大 5%（`fmSoft`），幾乎看不出來。改成跟桌機一樣四種鏡頭輪替，
   幅度加大：放大 16%、縮回、左右平移各 4%（放大 12% 底下平移，不會露出邊）。直式與橫式都套用。
4. 頁尾：拿掉「運河風車」Commons 標註與舞鶴公園字樣，新增「天神街景：日本國家旅遊局」。

## 驗收
- 直式三格截圖（10/28、11/01、10/29）、橫式兩格截圖：新照片正常顯示。
- 動畫數值：用 `getAnimations()` 讀出四種鏡頭各自的起始 transform
  （1.16 縮放、±16.8px 平移等），確認新規則生效。
- 限制：無頭瀏覽器的虛擬時間不會推進 CSS 動畫，所以「動起來的樣子」要在真手機上看。
