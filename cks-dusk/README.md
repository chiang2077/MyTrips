# 中正紀念堂・黃昏（three.js 全程式生成）

不用任何 3D 模型、貼圖或照片，全部用程式生成的黃昏中正紀念堂，輸出成 70 秒影片（10 顆鏡頭 × 7 秒）。

## 看預覽

用任何靜態伺服器開 `cks-dusk/`，例如：

```bash
cd cks-dusk && npx http-server -p 8080   # 再開 http://localhost:8080/
```

| 網址參數 | 作用 |
|---|---|
| （無） | 自動播放 10 顆鏡頭，下方有時間軸可拖曳 |
| `?mode=free` | 自由視角（滑鼠拖曳旋轉、滾輪縮放） |
| `?zones=hall,gate` | 只載入指定區域 |
| `?t=35` | 跳到第 35 秒 |

## 輸出影片

```bash
node tools/render.mjs --w 1920 --h 1080 --fps 30
# → out/segments/shot-01.mp4 … shot-10.mp4（可中斷續跑），最後串成 out/cks-dusk.mp4
```

在沒有 GPU 的雲端容器（SwiftShader 軟體算圖）上，1080p、4 倍 MSAA 每格約 8 秒，全片約 4.5～5 小時。

## 檔案結構

| 檔案 | 內容 |
|---|---|
| `src/layout.js` | **場景平面圖**：唯一的座標來源（單位公尺，x 向東、z 向南）。每個數字標註 [官方] 或 [估]，附資料來源網址 |
| `plan.svg` | 由 layout.js 畫出的平面圖（`node tools/plan.mjs > plan.svg`） |
| `src/materials.js` | 共用材質（草地、琉璃、屋瓦、木頭、地磚…），紋理全部程式繪製、可無縫拼接 |
| `src/rng.js` | 固定種子亂數；`Math.random` 也被換成固定序列，每次打開長得一模一樣 |
| `src/sky.js` | 程式生成的黃昏天空（漸層、日輪光暈、薄雲） |
| `src/scene.js` | 組裝：太陽（西南西 247.5°、仰角 7°、暖色）、天光、霧、陰影 |
| `src/shots.js` | 10 顆鏡頭：特寫小物件 → 停 0.9 秒 → 加速拉遠 → 結尾放慢 |
| `src/zones/*.js` | 8 區分別施工：地形、主殿、牌樓、廣場、兩廳院、庭園、樹木、外牆 |
| `CONTRACT.md` | 分區施工規範 |
| `tools/snap.mjs` | 截圖檢查工具 |
| `tools/render.mjs` | 逐格算圖＋ffmpeg 編碼 |

## 尺寸依據

官方數字（主殿 70 m＝臺基 14.5＋主體牆 24＋斗栱至寶頂 31.5、上層大廳 40 m 見方、牌樓 30×80 m、側門 13.8×19.7 m、民主大道 40×380 m、兩池各約 3,000 m²、園區約 25 公頃）來自國立中正紀念堂管理處官網與園區建築導覽，網址列在 `layout.js` 開頭。官方查不到的（臺基邊長、兩廳院量體、側門與池塘確切位置等）依參考照片比例估算，標為 [估]。

## 已知簡化

- 中軸對齊正東西（實際略有偏角）。
- 西側城市建築不投射陰影（物理上 7° 夕陽會讓 40 m 高樓影長約 330 m，把牌樓與廣場整片蓋住）。
- 池面只反射天空，沒有拱橋倒影。
- 匾額字型取決於執行環境的中文字型。
